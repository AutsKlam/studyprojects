# 首次用户体验反馈

日期：2026-11-11；来源：用户在主对话中的直接反馈与优先级选择。

## 原始反馈

1. “目前前端似乎只能新建工单保存，无法提供图片，无法删除”
2. “工单和资料库采用滑动形式，可看到的条数少。且无法查找”
3. “侧边栏无法隐藏”

用户随后选择：**先做搜索、列表布局和侧栏折叠**。

## 转成可验收的需求

| 需求 | 本轮范围与验收方向 | 状态 |
| --- | --- | --- |
| 工单与资料查找 | 按标题或正文关键词查询；结果数量明确；清空恢复列表；无匹配有提示 | S1 R0 已选定 |
| 列表看得更多 | 采用紧凑列表，移除列表区域内独立滚动；提供分页，详情不长期挤占列表空间 | S1 R0 已选定 |
| 侧栏可隐藏 | 可折叠和展开；收起后内容区变宽，导航仍可访问；窄屏可开关导航 | S1 R0 已选定 |
| 工单图片 | 拟先支持附件上传与预览；是否需要识别图片内容，在正式排入时确认 | 待办，未实施 |
| 删除记录 | 拟提供明确的删除入口与取消路径；工单/资料范围及是否可恢复，在正式排入时确认 | 待办，未实施 |

列表和侧栏的具体实现由 Planner 制定；“标题或正文关键词”是当前最小搜索合同，不把它等同于语义检索或资料问答。

## 学习证据与边界

- 用户已提供基于界面体验的具体反馈，并亲自选择下一轮优先级；不再记为“尚未体验”。未读取或猜测用户具体录入了哪些记录。
- 这些反馈用于 S1 的真实需求输入，但修改与用户复验尚未发生，不能据此宣称 S1 已达标或用户已掌握实现原理。
- S0 保留已验收基线；S1 使用新的独立私有子仓。详情见 [S1 R0 任务单](../tasks/S1-R0.md) 与 [S1 状态](S1-STATUS.md)。
