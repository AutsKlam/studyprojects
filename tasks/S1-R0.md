## 本轮范围与验收

| 编号 | 验收条件 |
| --- | --- |
| B1 关键词搜索 | 工单与资料均可按标题或正文关键词查找；清空恢复列表；总数准确；无结果有提示；异常可重试。中文、空白、特殊字符和连续切换条件有合理处理 |
| B2 列表布局 | 移除原卡片列表内独立滚动，使用紧凑列表和分页；同一桌面视口比 S0 显示更多完整记录。详情按需打开，不持续分走列表宽度；窄屏不横向溢出 |
| B3 侧栏折叠 | 桌面可收起与展开，内容区域随之调整；收起后仍能导航；窄屏可打开和关闭导航，不挡住操作 |
| B4 原功能回归 | 创建、详情、换行/纯文本、严格输入校验、种子幂等和重启持久化继续可用；搜索和翻页不得丢失或修改记录 |
| B5 交付 | 私有子仓真实 PR、独立审查、针对性测试与浏览器前后证据；用户复验另行记录，Agent 不代验收后宣称学习达标 |

页大小、搜索提交方式、详情抽屉/页面等常规设计由 Planner 决定，写清取舍。查询不应只过滤当前页；不改动既有记录内容。可新增必要接口参数；对原列表接口兼容策略需明确。

本轮不实现图片、删除、编辑、模型调用或 RAG。图片和删除保留于用户反馈待办；资料问答在 S1 后续轮次实施，不降低固定阶段目标。
